# QMSum train8 匿名事实审计 v1

这是 **LLM-assisted single judge** 审计，不是人工评测，也没有第二评审者一致性验证。评审者继承一般项目上下文，但审阅时仅访问匿名候选队列、其提供的完整会议原文和本目录自己的输出；未访问候选映射、方法/预算结果、实验实现或 git 历史。没有按方法或预算汇总。

先冻结 `rubric_v1.json`，再对 128 条候选逐项人工式阅读判断（由语言模型执行），分 32 条阶段保存。8 份原文的全部 4,139 行已按连续块阅读，覆盖 32 个问题。Python 仅用于呈现文本、序列化已作出的判断、核对哈希与计数，不以词匹配替代事实判断。

`train8_claims_v1.jsonl` 保留每个 `item_id` 的主要可验证 claim、支持/矛盾/无法核实标签、原文行证据、问题覆盖、事实通过与不确定标记；`train8_summary_v1.json` 保存队列、rubric、判断文件和全部来源的 SHA-256，以及完整性检查。

总体计数仅用于审计记录，不能直接推出任何方法间差异：128 条中事实通过 50 条，42 条存在无法核实或重要解释不确定；覆盖 0/1/2 分别为 3/78/47。主要 claim 共 733 项，其中支持 608、矛盾 75、无法核实 50。事实通过严格要求所有主要 claim 受支持；非实质省略可事实通过，但覆盖仍可能不足。

若 claim 标为无法核实，所列行号是最相关的讨论上下文，而不是声称该局部文本足以证明全篇不存在支持。所有此类判断都建立在完整原文阅读之后。问题覆盖以问题、参考摘要和原文共同确定，参考摘要不高于原文。原文存在口语停顿、自我修正、不同发言者附和及未定提议，归因和结论强度因此有一定主观性；复核应优先查看这些不确定样本。

参考摘要自身存在错误或过度简化，例如 d357 原文 137–139 行允许强硬塑料，并非一概排除塑料；其结尾原文的任务分工也不能照参考摘要复制。63e 原文明确区分 5 Hz 空调噪声与混响，并区分较早的常规投稿与 5 月 13 日 Aurora 专场延期；评审没有要求候选重复参考摘要中混淆的说法。

阶段提交用于固定进度，不涉及解盲。后续方法比较应由另一流程连接映射，并保留文档聚类结构；本审计不能替代人工事实核验。
