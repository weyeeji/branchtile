# 较快原生阶段的次要敏感性分析

在首次六文档及三个额外重复的部分结果已观察之后，增加统一的次要分析。它不能替换已经冻结的 ABBA 均值主指标，不是新的事前主评估，也不称为固定 baseline 或统计置信下界。

对六个可行文档的首次、repeat1、repeat2全部18个进程统一计算：

`min(A0 anchor+generate, A3 anchor+generate) / (mean(B1 anchor+generate, B2 anchor+generate) + 本进程完整未摊销setup)`。

完整setup仍包括离线资格核对、配置、production图建立和setup receipt导出。取的是较快的完整原生cold任务，不能从不同阶段拼接最快anchor和最快generate。候选分母及setup和主指标完全相同。

每个进程保留所有四阶段原始计时、ABBA主值、次要值、选中的原生阶段，以及A0/A3的generate和cold有符号比值。所有原八文档仍保留在每轮覆盖/失败分母中，不只分析有漂移的14/16/18，失败不给虚构比值。

报告每轮的条件几何均值与总时间比，每文档三次值及完整三次均值。相同文档的重复不是新增泛化样本；跨轮输出/轨迹的一致性由原冻结重复审计独立判断。跨所有进程的汇总仅用于描述，不能把18次进程或72个阶段当作独立文档样本。

若A0系统性慢于A3，记录这种模式，但单凭ABBA不能确定是JIT首次使用、缓存、GPU热状态/功耗、其他任务或主机争用导致。不从该分析外推固定温度、固定时钟或已消除干扰的结论，不增加GPU实验。
