# 跨问题/跨步低秩 residual 与误差证书审计

2026-10-16。**本轮没有满足新颖性和成本依据的候选，不建议 GPU 实验。** 这不是断言有限误差 attention 不可能加速：具体被排除的是“围绕已算 Q 缓存输出/Jacobian，低秩修正，再加通用 Taylor bound 和 fallback”这个组合。下文保留可复用的正确性合同与成本门槛，不给组合另造名称。未改协议、模型、评价集；只用项目 venv、CPU 和一手文献，未读正式答案或事实审阅。

## 公式级先例，而非只按名字排重

- **MuSe，首稿 2025-09-12，最新核查 v4 2026-06-30。** [Appendix B，式 8–15](https://arxiv.org/html/2509.10406v4#A2) 已围绕 query 中心展开输出，线性项是指数倾斜分布下的 `Cov(V,K) δq`，并同时展开 mass。还讨论协方差预合并、跨 query 中心共享及与精确 retrieval 的去重。这直接覆盖本轮的 Jacobian residual 核心；它主要研究训练，不代表已经实现本项目的跨步证书。
- **[RESA，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/89bd6217280d1417370c89ee493ba3c7-Abstract-Conference.html)** 使用 prefill Q 建立 rank-one logits prior 并在线估计稀疏 attention 遗漏的残差。它不是固定支持上的严格误差证书，但排除了宽泛的“prefill 得低秩先验，decode 修正”主张。
- **[Runtime-Certified Bounded-Error Quantized Attention，2026-05-20](https://arxiv.org/html/2605.20868v1)** 已研究逐 head/step 可计算误差界、升级与生产 dense fallback；其量化对象不同，不能声称与本方案逐字相同。它也明确区分同计算路径的数学参考、生产 kernel 的舍入差及最终生成质量。因此“附证书与回退”本身不足以补足创新。
- **[Error Certificates for KV-Cache Eviction，首稿 2026-07-23、v3 2026-08-29](https://arxiv.org/html/2607.21475v3)** 已有随机设计、attention 误差估计和触发恢复。v3 包含严重损伤/长对话的正结果，同时保留 LongBench gate 失败边界；不能将早版负结果概括为证书无用。其采样/加权会改变计算表示，故不是固定原 mask 的直接实现。

跨问题相同文档只是可能的摊销条件；尚没有区别于这些工作的低成本、可兑现执行机制。也不能仅因目标场景不同就宣布没有发表空间：真正缺少的是新增机制或可推广现象及其证据。

## 固定支持上确实可计算的合同

以下是普通 Taylor 余项核算，**不作为新理论**。设 S 为该请求已经冻结的支持，K/V 是同一 BF16 或原生 FP8 解码后的参考表示，位置/RoPE 不变。以 q₀ 定义

`pᵢ=softmax(q₀·kᵢ/√d), y=Eₚ[v], μ=Eₚ[k], J=Covₚ(v,k)/√d`。

对 `h=q−q₀`，用 rank-r 矩阵 Jᵣ 估计 `ŷ=y+Jᵣh`。预先获得有效上界 `λ≥||J−Jᵣ||₂`、`Rᵥ=maxᵢ||vᵢ−y||₂`、`Rₖ=maxᵢ||kᵢ−μ||₂`。令

`ρ=||h||₂Rₖ/√d, R=exp(ρ)−1−ρ`，则实数运算下

`||O(q)−ŷ||₂ ≤ E := λ||h||₂ + (Rᵥ+||Jᵣh||₂+λ||h||₂)R`。

证明要点：`dᵢ=h·(kᵢ−μ)/√d` 的 p 均值为零且 `|dᵢ|≤ρ`；`rᵢ=exp(dᵢ)−1−dᵢ` 非负、均值不超过 R。将归一化输出写为 `(y+Jh+Eₚ[v r])/(1+Eₚ[r])`，减去 `y+Jh` 后用范数三角不等式，再加低秩残差界即可。概率 p、中心、半径、λ 都必须对应**当前准确支持和参考表示**。

还须同时返回 mass：`Ẑ=Z(q₀)exp(h·μ/√d)`，满足 `1≤Z(q)/Ẑ≤1+R`。只证输出而沿用旧 LSE 不安全：公共 V 全为 1、私有 V 为 −1 时，公共输出始终为 1，但公共/私有 mass 比从 1 变成 9 会令合并输出从 0 变成 0.8。

若私有尾 `(Zₚ,yₚ)` 精确计算，令 `a=Ẑ/(Ẑ+Zₚ)`、`Δ=Ra(1−a)/(1+Ra)`，则用 `aŷ+(1−a)yₚ` 合并的误差不超过 `(a+Δ)E+Δ||ŷ−yₚ||₂`。实际实现还需计入浮点舍入与 native reference 的路径差；上述实数证明不能直接称为 BF16/FP8 严格 runtime certificate，更不能推出自然生成质量保证。

## 为什么现在还没有便宜可用的方案

1. **支持和概率无法免费跨问题共享。** 不同问题有不同 S、q₀、p 和 J；公共物理 KV 并不令这些统计量相同。GQA8 的八个 query head 也不能平均后冒充各头保证。对全源求 J 后直接用于子集，会改变已冻结语义。
2. **便宜检测不等于便宜构造。** 完整 J 直接构造为 O(Nd²)；投影构造可做到 O(Ndr)，但还需有效 λ。未经残差控制的随机 sketch、尾奇异值猜测和均方拟合误差都不是 λ 的证明。全局 Rₖ 可能使 R 很松；细分块能收紧却增加统计量、扫描和精确合并成本。尚未测得本模型证书接受率。
3. **存储存在具体取舍。** 主模型 TP2 每 rank 有 16 query heads、48 层、d=128。B3 每请求/head 独立 FP32 J 共 144 MiB；rank8 两个独立因子共 18 MiB。若每 128-token 块存一组因子、支持为 32K，增至 4.5 GiB/rank，仅包含因子。共享右因子可减少一部分，但需证明其残差；这些是示例设计的成本，非所有算法的下界。
4. **接受率必须对应真正省掉的执行单位。** native XQA/E0 调用、head 分组和图执行不会因为某个 head 的证书成功就自动跳过。若任一失败仍调用整组 native attention，成功 head 的算术近似只是额外工作。必须计入检测、分流、精确私有尾、合并、刷新及图适配，不能把任意逐头 hit rate 换算为总节省。

设 Tₙ 为同支持/同精度的完整原生调用，h 为可真正跳过的执行单位比例；T𝚌、Tₐ、Tᵣ/H 分别为证书、近似和刷新摊销。即使乐观忽略额外分流成本，也只有

`Tnew ≈ T𝚌+Tₐ+(1−h)Tₙ+Tᵣ/H`。

要超过原定 1.15×，必须 `h>0.130435+(T𝚌+Tₐ+Tᵣ/H)/Tₙ`；若门槛按延迟降低 15% 表述，则常数为 0.15，不能混用。当前 sparse replay 可替换占比约 20%–25% 只适用于该边界；即使 attention 1.15×、准备为零，整步也仅降低 2.61%–3.26%，仍不足以自动满足原应用约 5% 目标。原生 FP8 与 BF16 必须各自作同精度参考，不能以误差较大的精度替代去制造收益。

## 已完成的最小 CPU 证据与停止边界

[脚本](../scripts/audit_query_residual_certificate.py) 与 [JSON](../results/platform/query_residual_certificate_20261016.json) 可复算三项：

- rank-one logits 不保证 attention 低秩：`q=log(x), x=1..4; k=0..3` 的 softmax 矩阵为归一化 Vandermonde，精确有理 determinant 为 **1/17000**，rank 为 4。
- cosine 不是误差证书：`q₀=(1,0), q=(1,.001), k±=(0,±10000), v±=±1`，cosine 为 **0.999999500000375**，输出却改变约 **0.9999985573**。这是数学反例，不是实测模型范数；K-aware 界会拒绝它。
- 3,000 个小型 float64 随机算例检查上述输出、mass 和私有尾合并不等式，全部通过；只是推导的数值 sanity，不是自然数据接受率或有限精度证明。

三份现有 suffix_v2 rank0 的 decode 文件只含 steps **1/16/64/256**（48/48/64 文件），没有连续 2/3 步。因此不能把这些间隔样本冒充连续复用命中率，也不能据此估算 H。此处只清点文件名，未读取模型答案。

**现在停止在 CPU 审计，新增 GPU 预算为 0。** 重新进入需先有不同于现成 covariance/Taylor/fallback 组合的具体贡献，并解释如何以低于同支持 native FP8/BF16 的成本取得有效残差界和跳过完整执行；随后才值得申请连续真实 Q 的有界证书接受率验证。支持必须保持完全相同，成本含全部准备/刷新，局部数值通过后仍须过冻结自然质量和完整应用门槛。仅增加更多负点、调大容差或改名不能满足这些条件。
