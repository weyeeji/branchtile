## 审计与尚存限制

`results/grouped_hint_next8_production_final_audit_v1.json` 由预冻结汇总脚本生成，六个任务各有独立 `independent_analysis.json`，全部 source/build/输入哈希和清洁退出通过。离线训练资格覆盖双rank各125个真实状态、每状态48层；heldout完整输出检查不等于逐个heldout隐层全部逐位检验，更不是所有可能输入的数学等价证明。

`results/grouped_hint_next8_source_integrity_v1.json` 从全部三份原始parquet独立重建了98题及其全部来源、答案冲突状态和原文哈希，没有选题替换或文档截断。这个检查证明数据来源完整性，不自动证明所有参考答案或PDF表格语义无误。

`results/grouped_hint_next8_allocation_final_v1.json` 覆盖六次分配，未发现账本记录的同卡时间重叠。它不能排除未记录活动、主机争用、温度/功耗或时钟差异。

eval14、16、18的原生 A0/A3差异约5%、9.6%、9.9%，所以单次ABBA不是稳定性证明。**所有六个可行文档各增加两次重复**已于 `fcc6c1a` 统一冻结；冻结时尚未查看eval14性能，首次结果保持本表主结果，不择优替换。重复只能说明相同输入的运行噪声，不能冒充更多未见文档或把层/步数当独立样本。重复失败、跨轮轨迹变化和原来的两个配置失败均保留。
