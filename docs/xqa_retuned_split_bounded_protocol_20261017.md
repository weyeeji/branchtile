# Fixed coverage split experiment (B8, BF16)

This is an auxiliary performance mode, not a new sharing mechanism or a claim of matching the original default output bits. The earlier native-schedule direct-input implementation remains frozen. This experiment uses exactly the same generated CUDA arithmetic and address map, changing only the split count passed to both stages.

The rule is fixed before results: `S' = min(max(1, SM // (ceil(B/2) * Hkv)), ceil(table_token_capacity / 256))`. For the two declared B8, Hkv2 captures on a 170-SM GPU, default S is 10 and S' is 21. The prefix grid grows from 80 to 168 CTAs, while the tail and native counterfactual use 336 CTAs. These are launch sizes, not measured hardware occupancy. No query content, observed timing, or per-input best implementation selects the rule.

Five complete-call graph arms are retained: original native PDL-on; its AA repeat; current direct-input sharing at original S; native PDL-on forced to S'; and direct-input sharing at S'. The original native remains the primary baseline. The S' counterfactual isolates sharing from split tuning and cannot replace the primary baseline.

Numerical gates require original-S candidate versus original native bits, S' candidate versus S' native bits, native AA bits, and FP64 attention agreement for every arm (`atol=.006, rtol=.015`). They explicitly report, without requiring equality, S' versus original native differences. Six predetermined prefix checkpoints compare all live raw U/m/z/backward-hint fields against independent unshared GQA8 states with the same S'. The checkpoints include the split-stride boundaries and the former hint-control trigger at 339 tiles. The graph is replayed with changed Q and unequal lengths, NaN old state, restored inputs, and final revisits. These finite checks do not prove all-input exactness.

The full calls contain both prefix and tail/final-merge kernels; there is no online Q/page/length packing in these graph arms. The raw-state requirement rises from 1,433,600 bytes at S10 to 3,010,560 bytes at S21. Both plans retain their own state and share a 64-MiB candidate workspace sequentially. The unshared raw-state oracle and FP64 calculations are outside timing. Each arm is warmed identically; 30 randomized paired blocks measure hot 10-replay means and cold single replays after a 256-MiB flush. Cold event quantization is a limitation. A separate CUPTI trace must confirm the actual grids and graph kernel counts.

The first cases are the original full-B8 captures train1/rank0/layer15 and train7/rank1/layer47, with original BF16 cache strides and physical IDs. No synthetic extra tails or query duplication is admitted. Continue beyond this bounded test only if all numerical gates pass and both hot paired lower 95% bounds for `direct_nativeS/direct_retunedS` exceed 1.03. A successful operator result would still require natural-output quality and cost testing: prior changes to floating-point order changed generation lengths enough to erase substantial graph gains. No whole-model, energy, paper novelty, or quality claim follows from this test.

The runtime and runner are independent files. CPU syntax/rule/invalid-input checks passed with `CUDA_VISIBLE_DEVICES=''` and no CUDA initialization. GPU execution is reserved to the parent allocator through `scripts/run_jobs_locked.py`.
