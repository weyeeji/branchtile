# PAT compat fixed scheduler: performance artifact and qualification

The NaN debug repair independently passed single/multistream checks on the first real capture. The new performance artifact restores original `api.h` and `bindings.cpp` from the v4 stream-compatibility source, removing NaN fills, retained temporary tensors and metadata debug bindings. The guarded scheduler is byte-identical to the qualified repair, and all four CUDA object files are reused unchanged. The receipt records hashes; CPU compilation hides GPUs and does not import FlashInfer. This is a locally modified PAT baseline, not unchanged upstream.

Before timing, validate the new allocation/lifetime behavior with 30 repeated full calls on each of two real native-BF16 captures: train1/rank0/layer15 and train7/rank1/layer47. Each uses original full page tables, physical KV identities and strides, and native Q values. Cross each capture with local multistream/default caller, official `DISABLE_STREAM=1`/default caller, and local multistream/nondefault caller. A separate memcheck matrix covers all three modes across those captures. Root launches all jobs via `scripts/run_jobs_locked.py` and must inspect terminal status and sanitizer errors before using timing.

The eager comparison has four arms: native XQA with PDL, native AA, locally fixed PAT, and **grouped-hint-corrected** RawPair. The old incorrect hint behavior is not used. Every arm is eager on the same declared caller stream. PAT includes temporary allocations, stream/event creation and joins, all forward tiles and gather. RawPair includes Q packing, page/length copies, raw state and native tail/merge. Metadata tree construction and upload are separately measured; no claim treats online host readback as free.

Each performance run first repeats full numerical checks30 times. It then measures30 randomized paired blocks in both hot and 256MiB-flushed conditions, with5 repeated eager calls per hot sample and1 cold call. Caller-stream CUDA events and synchronized wall time are both retained, alongside native-AA variability and paired-bootstrap intervals. Every block receives an outside-timing FP64 gate; the next arm restores its prescribed warmup or flush. PAT is allowed normal numerical differences if FP64 tolerance passes; native AA and corrected RawPair require int16 equality. Results are operator-only, not end-to-end evidence.

Four prepared manifests cover qualification wave A/B, memcheck and eager measurement. Their GPU numbers are scheduling suggestions for root, not reservations or automatic launches. No GPU was started during preparation. Original upstream/default, single-stream and unsuccessful stream-patch artifacts remain preserved and cannot be reclassified as valid by the later repair.
